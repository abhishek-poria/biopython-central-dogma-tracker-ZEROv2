# ZERO 2.0: Biopython & Data Logging Assistant 🧬

This is the upgraded 2.0 version of my personal AI assistant, ZERO. Moving past basic Python structures, this iteration integrates professional computational biology tools and persistent data storage.

## 🚀 New Advanced Features
- **Biopython Integration:** Utilizes `Bio.Seq` to handle real transcription (DNA ➔ mRNA) and translation (DNA ➔ Protein) computations instantly.
- **Automated Data Logging (File I/O):** Automatically appends and logs analyzed DNA sequences into a local `centraldogma.txt` database file.
- **Robust Error Handling:** Implemented `try/except` blocks to catch data type errors and prevent application crashes.
- **Biochemistry Dictionary:** Maps secondary metabolites and tracks amino acid classifications based on their specific chemical R-groups (Glycine, Alanine, Serine).

## 📦 Dependencies Used
- `biopython`
- `rich`
- `pyttsx3`
